# Bootstrap — GoBadminton CLEAN

1. Проверить, что репозиторий — `anpavel84-afk/gobadminton-clean`.
2. Прочитать [AGENTS.md](../../AGENTS.md) и полностью [единый регламент](../rules/ENGINEERING_OPERATING_MODEL.md) из принятой ревизии.
3. Установить свою роль и exact active assignment; не выбирать задачу по дате/памяти.
4. Зафиксировать commit правил, base/candidate, allowed paths/effects, writer/lease и допустимый маршрут.
5. Прочитать предметные документы только своего scope и [правила handoff](../rules/PROJECT_RECORD_POLICY.md).

PMA использует [checklist](../operations/chatops/PM-CHEATSHEET.md). Исполнителю нужен защищённый task worktree на разрешённой Германии; PLAN не является execution route. GitHub Projects/Issues и Actions заменяют исторические очереди/Hub в текущей модели.

Bootstrap не запускает процесс, не активирует провайдера, не выдаёт root/PROD и не делает draft canonical. Применять фактические права и проверенный установленный adapter. GoBadminton и BadmintonOpen — разные проекты.
