# Bootstrap — применение единого входа

Начать с [START_HERE.md](../../START_HERE.md), а не с dated launcher. Это один путь для PMA, Advisor, planner, author, QA, diagnosis и OPS.

Перед эффектами подтвердить: repository identity; текущую назначенную роль; accepted rules commit/hash и реально полученные bytes/full-or-scoped profile; exact assignment/base/candidate; allowed paths/effects; writer ownership; qualified requested/effective route. Полный текст обязателен PMA при takeover и reviewer правил; worker profile определяется §10.3 канона, не этим checklist.

Смена PMA не означает повторный старт или отмену существующего процесса. Сверить [CURRENT handoff](../handoffs/CURRENT.md) и [Master Plan](../ops/AI_TRAIN_MASTER_PLAN.md) с доступным live evidence. Недоступность GitHub, artifacts или protected state обозначить точно, без выдуманного PASS и без расширения доступа.

Bootstrap не создаёт admission, не включает провайдера и не выдаёт права на PROD. [Project Record Policy](../rules/PROJECT_RECORD_POLICY.md) задаёт долговременный результат.
