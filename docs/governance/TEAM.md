# Роли GoBadminton CLEAN — указатель

Полномочия — **§3**, выбор моделей — **§5** [Engineering Operating Model](../rules/ENGINEERING_OPERATING_MODEL.md). Другой самостоятельной таблицы ролей или model IDs здесь нет. Общий вход — [START_HERE.md](../../START_HERE.md).

Действующий mutating PMA определяется точным решением Owner и [CURRENT handoff](../handoffs/CURRENT.md), не историческим именем чата. Advisor остаётся советником, кроме отдельного явно ограниченного поручения Owner; такое поручение не создаёт второго runtime PMA и требует исключить пересечение writer scope.

Назначенная модель получает роль, полномочия и exact task через существующий trusted путь. Автор, диагност и принимающая QA — разные сессии и функции; название бренда само по себе не доказывает независимости. Продуктовый backlog — GitHub Issues/Projects, состояние исполнения — Actions/receipts.
