# Регламент GoBadminton

## Файлы
- Макеты, фото, референсы — только на files.anpavel.ru (https://files.anpavel.ru/projects/gobadminton/design/...), никогда не в GitHub.
- В GitHub — только документы с текстом, решением и ссылкой на файл.
- Адрес хранилища: files.anpavel.ru (не путать с похожими). Загрузка — через gb-run job design-upload.

## Порядок
- Сначала файл или макет на месте и решение в docs/decisions, потом публикация задачи. Никогда наоборот.

## Содержание задачи
- Ссылка на файл на files.anpavel.ru.
- Текстовое описание.
- Что делать.
- Ссылка на решение.

## Роли и правила владельца
- Go Bad управляет: ставит задачу промпт-райтеру (Codex) с требованием экономии токенов: простые задачи не на дорогие модели и не на xhigh.
- Промпт-райтер пишет тела и распределяет задачи по исполнителям (Codex, Cursor, Antigravity и др.) с учётом цены.
- Выбор исполнителей Go Bad при необходимости оперативно согласует с владельцем.
- Go Bad следит за выполнением, перезапускает зависшую очередь, смотрит длительность зависаний, разруливает очередь, отправляет на доработку. Сама не разрабатывает.
- Не дробить фичу на этапы, где следующий переписывает предыдущий.
- На карте только попапы, никаких переходов.

## Выбор моделей
Владелец 19.10.2026 21:41–21:43 BRT.
- Схема: владелец → Go Bad ставит цель → Codex (техн. PM на VPS) читает задачу и код, оценивает сложность и риск, предлагает план и маршруты → Go Bad согласует → исполнитель запускает автора → отдельная QA точного SHA → CI → DEV → браузерная проверка Go Bad.
- Таблицу маршрутов составляет Codex на VPS; Go Bad её не пишет и не правит, только согласует.
- Каждый модельный шаг: клиент (Codex/Cursor/Antigravity), точный проверенный model ID этого клиента, явный effort, роль (план/автор/QA/диагностика), резервный маршрут.
- Не считаются назначением: «по умолчанию», auto, «так же», одинокий effort, версия CLI. ID не выдумывать и не переносить между провайдерами.
- Cursor недоступен до 2026-10-23: до этой даты основными только Codex и Antigravity. Fallback с Cursor: сопоставимая модель Codex с явным effort, внутри согласованной таблицы без нового вопроса.
- Недоступность модели, квота и ошибка авторизации не тратят попытки исправления кода. Перед переключением проверить, что прошлый запуск завершён и ресурс свободен; история, изменения автора и счётчики сохраняются.
- В журнале: предложенные и фактические модель и effort, причина fallback, результат; неподтверждённое писать UNKNOWN.
- Таблица маршрутов TR1 от Codex (запуск codex-ops routing-table-20261020T004511Z-1284106) утверждена владельцем 19.10.2026 22:27 BRT; строки без брифов уточняются Codex и согласуются Go Bad.
- Исключение владельца 19.10.2026 22:27 BRT: установщик model-routing может заменить обёртки codex-review и codex-ops и записать /etc/gb-ops/model-routing.json, с бэкапом и --remove.
