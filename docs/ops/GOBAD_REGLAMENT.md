# Регламент GoBadminton

## Файлы
- Макеты, фото, референсы — только на files.anpavel.ru (https://files.anpavel.ru/projects/gobadminton/design/...), никогда не в GitHub.
- В GitHub — только документы с текстом, решением и ссылкой на файл.
- Адрес хранилища: files.anpavel.ru (не путать с похожими). Загрузка — через gb-run job design-upload.

## Порядок
- Сначала файл или макет на месте и решение в docs/decisions, потом публикация задачи. Никогда наоборот.

## Содержание задачи
- Ссылка на файл на files.anpavel.ru.
- Текстовое описание.
- Что делать.
- Ссылка на решение.

## Роли и правила владельца
- Go Bad управляет: ставит задачу промпт-райтеру (Codex) с требованием экономии токенов: простые задачи не на дорогие модели и не на xhigh.
- Промпт-райтер пишет тела и распределяет задачи по исполнителям (Codex, Cursor, Antigravity и др.) с учётом цены.
- Выбор исполнителей Go Bad при необходимости оперативно согласует с владельцем.
- Go Bad следит за выполнением, перезапускает зависшую очередь, смотрит длительность зависаний, разруливает очередь, отправляет на доработку. Сама не разрабатывает.
- Не дробить фичу на этапы, где следующий переписывает предыдущий.
- На карте только попапы, никаких переходов.

- Исключение владельца 19.10.2026 21:14 BRT: для executor-ghread разрешены п.3 (токен чтения GB_GH_READ_TOKEN для api.github.com) и п.4 (штатный запуск check_foundation.py исполнителем).
- Исключение владельца 19.10.2026 21:14 BRT: сервисам слотов разрешена доп. группа gb-slots с записью в общие блокировки (дизайн PR #100).
- Исключение владельца 19.10.2026 21:37 BRT: для executor-ghread в исключение по п.3 входит SSH-ключ исполнителя для git push (только штатный push, без копирования и вывода).
- Решение владельца 19.10.2026 21:37 BRT: исключения владельца для ревью установщиков лежат в /etc/gb-ops/review-exceptions.d/<installer>.txt (root:root 0644, пишет только root); ревью отмечает покрытые находки как WAIVED, исключения внутри скрипта не действуют.
