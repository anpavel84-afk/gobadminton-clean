# Workbench — предложения и сохранённые проверки

**Не второй канон и не текущая очередь.** Начать с [START_HERE.md](../../START_HERE.md). Активные правила — [единый регламент](../rules/ENGINEERING_OPERATING_MODEL.md), текущие этапы — [Master Plan](../ops/AI_TRAIN_MASTER_PLAN.md).

Материалы под этой папкой читаются в их исходной роли: рабочий проект, исследование, synthetic fixture, review-result или отчёт установленной конкретной версии. Само нахождение здесь не отменяет подлинность прежнего PASS/FAIL, но и не делает proposal принятой политикой.

Таблицы product-model-routing/phase-routing/context-exchange — источники происхождения; принятые требования представлены в постоянном каноне/контрактах. Их старые маршруты, singleton limits и «next» не являются свежими admissions. Runtime/evidence scripts не запускать только потому, что их нашли в этой папке.

Оригинальные журналы, FAIL/UNKNOWN и hashes сохраняются; candidate не может сослаться на workbench, чтобы ослабить свою QA. [Реестр всех семейств документов](../rules/DOCUMENT_REGISTER.md).
