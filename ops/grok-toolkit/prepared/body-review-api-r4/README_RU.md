# Разблокировка проверки публичных контактов площадки — r4

Статус: подготовлено, НЕ установлено. PR #102 не вливать.

Зачем: исправить противоречие между постановщиком и ревьюером задач, которое блокирует контакты площадки #134. Новая обёртка допускает независимое рассмотрение только узкой задачи публичных контактов; проверка не означает одобрение задачи. Все 12 проверок, ограничение 14 путей и самостоятельные QA/CI сохраняются.

Изменения: удалить копирование credentials исполнителя; использовать уже настроенный собственный home ревьюера; явно запрашивать gpt-6.1-sol/high и завершаться отказом без CLI-default retry. Новых пользователей, sudoers-прав, служб или доступа к другим проектам нет.

## Точная операция для решения владельца

Разрешить единственную защищённую замену `/usr/local/sbin/gb-ops/codex-review`, root:root 0755, штатным установщиком `body-review-api`, зафиксировать это ограниченное разрешение в `/etc/gb-ops/review-exceptions.d/body-review-api.txt`, затем повторить независимую проверку точного установщика. Установка допускается только после настоящего PASS/allowlist и успешного dry-run.
