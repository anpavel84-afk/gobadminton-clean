# Решения, нужные от Павла (с рекомендацией)
1. Изоляция слотов: отдельный systemd-unit на слот (рекомендую) или один supervisor с namespace. → **systemd-шаблон**.
2. Рабочий каталог: `git worktree` от одного clone (рекомендую, экономит диск) или отдельные clone. → **worktree**.
3. Пользователь ОС: отдельный на каждый слот (сильнее изоляция) или один общий. → **отдельный**.
4. Число слотов на старте → **2**, третий после 1 недели без инцидентов.
5. Порог UNKNOWN-квоты Codex: задать дневной лимит вызовов (например 40 на author, 40 на QA) или сначала измерить. → **лимит 40/40 плюс измерение**.
6. Ревьюер в цикле замены: Codex, пока cursor и agy выключены. → **да**.
7. Условия включения cursor (Auto): provider-тест на 3 задачах плюс ваше «да». → **да**.
8. Когда ставить: только в окно `idle` после #98. → **да**.
9. Порядок: сначала ops-ветка (порт `--slot` в исполнитель, QA и CI, без установки), потом одна root-команда. → **да**.
