# Design tokens

Место для самостоятельной визуальной системы GoBadminton. Цвета/типографика/spacing ещё не выбраны и не утверждены; эта папка не является готовым style guide.

Design Director формирует brief, Visual Designer создаёт экраны и primitives; после выбора направления semantic tokens экспортируются для web/native. Shared token не означает одинаковые UI controls и navigation. Контраст, states, touch targets и accessibility проверяются на обеих платформах.

Не импортировать BadmintonOpen styleguide как наследство. [Team](../../docs/governance/TEAM.md), [Quality](../../docs/quality/TEST_STRATEGY.md).
