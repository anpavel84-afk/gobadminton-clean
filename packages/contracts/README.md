# API и event contracts

[openapi.json](openapi.json) — первый schema-first **DESIGN_DRAFT** критического Game/Participation API, версия0.1.0. HTTPS server `.invalid` — placeholder. Ни одного реального endpoint этим файлом не запущено.

Правила: [API_POLICY](../../docs/api/API_POLICY.md). Business semantics: [STATES_AND_INVARIANTS](../../docs/domain/STATES_AND_INVARIANTS.md). JSON Schema/OpenAPI refs проходят текущую статическую проверку; полноценная schema validation и SDK generation — F-01.

Не копировать provider secrets, ORM tables или server permission engine в contracts. Event schemas добавлять одновременно с producer/consumer и migration rules; имена/outbox envelope определены в [модулях](../../docs/architecture/MODULE_BOUNDARIES.md).

## Owner game defaults (2026-10-06)

`CreateGame.title` is optional. The server trims custom titles and rejects more than 160 characters after trimming. Omitted/blank titles become `Игра` (regular) or `Игра с тренером` (trainer_led); response/stored titles remain non-null. Existing titles are unchanged; no migration. Discovery without a selected date uses cityId + startsFrom=now with no startsBefore; explicit city-day bounds and activity filters remain supported. The web create form starts with capacity 4; server capacity limits are unchanged.

Owner B adds optional-for-rollout `canRequestContact` to PublicPlayer and Radar
player projections. Current server emits it; older response omission means
unavailable in current clients. It is authenticated viewer-specific and never
replaces command revalidation. See the Owner B section of API_POLICY for fences.

## Unified Players Radar source candidate

Additive `/players/query` and `/players/query/map`, negotiated publishing v2 and purpose-bound result redemption are source staged with default-off capabilities. See [API notes](../../docs/api/UNIFIED_PLAYERS_RADAR_V001.md). `src/unified.generated.ts` is generated from OpenAPI; run `node scripts/generate-unified-types.mjs --write` from this package to regenerate. Normal contract check verifies generated bytes without writing them. This candidate does not enable runtime sharing or replace ordinary GET/G1 contracts.
